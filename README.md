# MR SAAS'y

MR SAAS'y is the internal enterprise control plane for MR Software products.

## Purpose

The platform provides shared capabilities for all MR Software SaaS products:

- Identity
- Tenant management
- Application registry
- Module management
- Security
- Compliance
- Operations
- Billing

## Principles

- Platform before product
- Contracts before extraction
- Tenant-first architecture
- No shared databases
- Products consume platform capabilities

## Current status

Foundation phase.

No product integrations exist yet.
